TRAVELVISTA - TRAVEL & TOURISM COLLEGE PROJECT

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another browser.
3. The website uses online Unsplash images and Google Fonts, so an internet connection is recommended.

Files:
- index.html  -> website structure/content
- style.css   -> design/responsive layout
- script.js   -> menu, scroll effect, contact-form demo

To customize:
- Replace the title/logo text in index.html.
- Change destination text and images in index.html.
- Change colors, fonts, spacing in style.css.
- The contact form is a front-end demo; it does not send email.
